Taller de Práctica Interactivo ("Tu Turno")

Comprueba y experimenta en vivo los conceptos del documento de estudio.

Tu turno 1: La Cascada y Especificidad

Dada la siguiente regla de CSS y elemento HTML:

p { color: blue; } .destacado { color: green; } <p class="destacado">¿De qué color se ve?</p>
Resultado en vivo:

¿De qué color se ve este texto?

Explicación: Se ve verde. Cuando dos reglas chocan, gana la más específica: una clase (.destacado) pesa más que una etiqueta (p). Si empatan en especificidad, gana la que aparece después.

Ajusta los deslizadores para ver cómo el padding afecta el espacio interno y el margin el espacio externo entre tarjetas:

Tarjeta B

Tu turno 3: Menú en una fila con Flexbox

Explicación: Flexbox ordena elementos en una dimensión (fila o columna). Aplicando:
nav ul { display: flex; gap: 1.5rem; list-style: none; padding: 0; }
Tu turno 4: Decisiones de unidades (rem vs px)

Simula el cambio de tamaño de letra de preferencia del usuario en el navegador para ver cómo reaccionan las unidades fijas (px) frente a relativas (rem):

🔴 Texto con 16px (Fijo - Ignora preferencia del usuario)
🟢 Texto con 1rem (Adaptable - Respeta la accesibilidad del usuario)
Explicación: El texto en rem se ajusta a la preferencia de accesibilidad de la persona; el de px la ignora. Usar rem para fuentes y espaciados asegura que tu sitio sea accesible.
